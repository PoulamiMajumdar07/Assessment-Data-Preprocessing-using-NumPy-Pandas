# Data Preprocessing using NumPy & Pandas
### Overview
#### This project demonstrates data cleaning, preprocessing, and analysis using NumPy and Pandas on a student dataset.

## Features
### NumPy Operations
•Created NumPy array from math_score

•Calculated mean, median, max, and min

•Normalized scores

### Pandas Exploration
•Loaded dataset

•Displayed first 5 rows

•Checked data types

•Found missing values

•Filtered attendance below 70%

### Data Preprocessing
•Handled missing values

•Converted exam_date to datetime

•Removed outliers using IQR method

•Removed duplicate rows

### Data Analysis
•Created average_score

•Found top 5 students

•Calculated correlation

•Grouped data by gender

### Technologies Used
•Python

•NumPy

•Pandas
